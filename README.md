# HousingOps
University housing operations and predictive room-change decision support using PostgreSQL, Python, and Streamlit.

DSCI-D 532 | Fall 2026

## Project Goals
- Track current and future housing vacancies
- Monitor RA coverage by residential floor
- Match room-change requests with compatible available spaces
- Analyze historical occupancy and demand

## Technology Stack
- PostgreSQL
- Python
- Streamlit
- GitHub

## Data
Public N.C. A&T housing data supplemented by clearly labeled synthetic operational records.
